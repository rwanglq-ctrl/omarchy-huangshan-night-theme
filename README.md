# 黄山·夜 Huangshan Night

夜山为底、云海白为字、日出金为印、松绿点缀的深色主题。壁纸：黄山日出、雪峰、云海与落日。

![preview](preview.png)

## 安装

```bash
omarchy theme install https://github.com/rwanglq-ctrl/omarchy-huangshan-night-theme
```
